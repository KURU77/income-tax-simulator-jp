# 所得シミュレーター

業務委託などの所得と給与所得を入れると、**その年分の税制**で年間の合計・課税額を試算し、非課税枠が残っていれば「あといくら稼げるか」を出します。

**→ https://kuru77.github.io/income-tax-simulator-jp/**

依存ライブラリなし、ビルド不要の HTML 1ファイルです。入力した金額はブラウザの中だけで計算され、どこにも送信されません。

## 画面の構成

ホームに結果の要約とメニューを置き、そこから各項目へ直接入ります。メニューには現在の入力値の要約が出るので、開かなくても状況が分かります。

| 画面 | 内容 |
|---|---|
| ホーム | あなたのタイプ・あといくら稼げるか・壁のメーター・メニュー |
| あなたのタイプを判定 | 3つの質問で一般／扶養親族／特定扶養親族を判定 |
| 一般向け／扶養親族向け／特定扶養親族向け | タイプごとに見るべき線・負担・知っておきたいことをまとめた専用ページ |
| 収入 | 給与と業務委託（年額または月ごと）・経費・年金 |
| あなたの状況 | 年齢・学生・障害者・寡婦ひとり親・誰の扶養か |
| 配偶者 | 収入・年齢・障害者区分 |
| 扶養親族 | 1人ずつ登録 |
| 所得控除 | 社会保険料・iDeCo・生命保険料など |
| お住まいと住民税 | 都道府県・市区町村（全国1,741団体）・均等割額・級地 |
| 他の端末と同期 | Google アカウントでログインして、パソコン・iPad・iPhone で同じ入力内容を使う |
| 試算の設定 | メーターの基準・入力内容のリセット |
| 税額の明細と試算枠 | 内訳と「あと◯◯円稼いだら」の比較 |
| 扶養している人と手取り | 階段グラフと段階表 |

URLのハッシュと連動しているため、端末の戻る操作で1つ前の画面に戻れます。広い画面では結果パネルを右に出したまま各項目を編集できます。

## できること

### あなたのタイプを判定して、専用ページで見る

初回に開くと3つの質問（年齢・誰の扶養に入っているか・学生か）で、次の3タイプのどれかを判定し、専用ページへ案内します。

| タイプ | 対象 | 専用ページで前面に出すもの |
|---|---|---|
| 一般向け | 誰の扶養にも入っていない人 | 住民税・所得税の壁、社会保険の目安 |
| 扶養親族向け | 親や配偶者の扶養に入っている人（19〜22歳を除く） | 「扶養している人の追加負担が0円で済む線」を先頭に置き、いま／その線まで／1円超えたとき（配偶者なら控除がなくなる直前）のあなたの手取り・相手の控除・相手の税額の増加・世帯で残る額を並べて比較 |
| 特定扶養親族向け | 19〜22歳で親の扶養に入っている人 | 特定親族特別控除を申請した前提で「親の控除を満額に保ったまま最も多く稼げる線」を先頭に置き、その線・上限まで稼いだときのあなたの手取り／親の控除／親の税額の増加／世帯で残る額を並べて比較。申請の手順（5章）も掲載 |

タイプは入力内容（年齢・扶養の有無）から自動で決まります。該当しないタイプのページを開くと、その旨と正しいページへの案内を表示します。ホームのタイプカードからいつでも切り替えられ、判定もやり直せます。

### 住所から住民税の地域差を反映する

都道府県と市区町村を選ぶと、その地域の均等割額と所得割の税率で計算します。

- **都道府県**：47都道府県の超過課税（森林・水源系の県民税）を均等割に反映。神奈川県は水源環境保全税として所得割にも上乗せ（令和8年度まで0.025%、令和9年度から0.018%）
- **市区町村**：全国1,741市区町村から選べます。合計税額が標準と変わる横浜市（横浜みどり税900円）と名古屋市（市民税の5%減税で所得割7.7%・均等割2,800円）は個別に反映し、それ以外は標準税率で計算します。政令指定都市の市・県の配分差は合計に影響しないため区別していません
- **年度の切り替え**：均等割は令和6年度から市3,000円＋県1,000円＋森林環境税1,000円、令和5年度までは市3,500円＋県1,500円として計算します

均等割額は住所から自動で決まりますが、チェックを外せば手で上書きできます。上記以外の市区町村で独自の超過課税がある場合は、この欄で調整してください。

級地（住民税の非課税限度額に使う区分）は手動で選びます。厚生労働省の公表PDFは多段組みで、機械的に読み取った結果の正しさを確かめきれなかったため、誤った非課税判定を出さないよう自動判定は入れていません。

### 年分ごとの税制を切り替えられる

いま選べるのは**令和7年分・令和8年分**（2025・2026年の所得）です。

| 年分 | 給与所得控除 | 基礎控除 | 所得税の壁 | 住民税の壁 |
|---|---|---|---|---|
| 令和7年 | 最低65万円 | 58万円＋上乗せ（最大95万円） | 160万円 | 110万円 |
| 令和8年 | 最低**74万円** | **104万円**（合計所得489万円以下） | **178万円** | **119万円** |

令和6年分以前（令和元年〜令和6年）は、**いまのところ選べないようにしています。**制度の差が大きく、ひととおり確かめきれていないためです。計算のコードはそのまま残してあるので、`index.html` の `YEAR_MIN` を下げれば元に戻ります。

令和8年分は**令和8年度税制改正（令和8年12月1日施行）**を反映しています。給与所得控除の最低保障額が74万円に、基礎控除は所得税法上の額が62万円となり合計所得489万円以下で104万円（489万円超655万円以下は67万円、655万円超2,350万円以下は62万円）。扶養親族・同一生計配偶者の所得要件は62万円（給与収入136万円）、勤労学生控除は89万円（同163万円）に引き上げられました。個人住民税は基礎控除43万円と非課税限度額が据え置かれる一方、給与所得控除と所得要件は所得税と同様に改正されます。収入220万円未満の給与所得は、改正で定められた別表どおりに計算しています。

**特定親族特別控除**（19〜22歳）は、親の控除が満額63万円になる線が年分で動きます。令和7年分は合計所得85万円以下＝**給与収入150万円以下**、令和8年分は同じ合計所得85万円でも給与所得控除が74万円になるため**給与収入159万円以下**です。控除がなくなるのは令和7年分で給与188万円超、令和8年分で給与197万円超です。

青色申告特別控除の選択肢や寡婦・ひとり親の区分も、その年に存在するものだけが表示されます。

出典：国税庁「[令和８年度税制改正（基礎控除の引上げ等関係）](https://www.nta.go.jp/users/gensen/2026kiso/index.htm)」「令和８年４月源泉所得税の改正のあらまし」

### 収入を月ごとに入力できる

給与と業務委託の収入は、金額欄の横の「月ごとに入力」を押すと、そのすぐ下に1月〜12月の入力欄が開きます。**月によって金額がバラバラでもそのまま入れられ**、合計と月平均が表示されます。毎月同額なら「1月の額を全月にコピー」で一括入力できます。

年額の欄はいつでも編集でき、月ごと入力中に年額を書き換えると12か月へ均等に割り振られます。

途中の月まで入力した場合は、そのペースで続けたときに**何月ごろ壁に到達するか**を試算します（年額で入れた項目は通年でならして計算します）。給与を月ごとに入れると、社会保険の106万円の壁の判定に使う「月額8.8万円」を超えた月も表示します。

### 入力内容は自動で保存される

入力した内容はブラウザの localStorage に自動保存され、次に開いたときそのまま続きから使えます。年分・月ごとの内訳・扶養親族の登録もまとめて復元されます。ログインしなければ保存先はその端末のブラウザだけで、外部には送信されません。消したいときは「試算の設定」にある「入力内容をリセット」を押してください。

### 他の端末とデータを同期できる（任意）

「他の端末と同期」から Google アカウントでログインすると、パソコン・iPad・iPhone で**同じ入力内容**を使えます。**はじめから有効にはなっておらず、ログインしなければ一切通信しません。**

保存先は利用者自身の Google ドライブの**アプリ専用フォルダ（appDataFolder）**です。ドライブの画面には出てこず、他のアプリからも読めません。求める権限は `drive.appdata` だけで、ドライブの他のファイルを読む権限は求めません。開発者のサーバーは存在しません。

| 場面 | 動き |
| --- | --- |
| 入力を変えた | 数秒後に自動でドライブへ送ります |
| 別の端末で開いた | 開いたとき・タブに戻ったときに受け取ります |
| こちらだけ変わっていた | こちらの内容で上書きします |
| 向こうだけ変わっていた | 受け取って画面に反映します |
| 両方が前回の同期より後に変わっていた | 勝手に消さず、給与収入・扶養親族の人数・最後に変えた時刻を並べて**どちらを残すか選んでもらいます** |
| オフラインのとき | 何もせず、つながったときに同期します |
| ログインが切れたとき | 黙って取り直せるなら取り直し、できなければ「もう一度ログインしてください」と出します |
| ログアウトしたとき | その端末は以後通信しません。端末の入力内容とドライブ側の内容は残ります |

同期をやめてドライブ側も消したいときは、Google アカウントの[ドライブの設定](https://drive.google.com/drive/settings)にある「アプリの管理」から、本アプリの非表示のデータを削除してください。

### あといくら稼げるかを壁ごとに出す

**給与で稼ぐ場合と業務委託で稼ぐ場合の両方**について、収入を増やしながら二分探索して壁の直前の金額を求め、それぞれ明記します。業務委託は必要経費を足さない前提なので、青色申告特別控除の使い残しがあるとその分だけ枠が広くなります。

- 住民税の均等割・所得割
- 所得税
- 親などの扶養控除、特定親族特別控除（19〜22歳）
- 配偶者控除・配偶者特別控除
- 勤労学生控除
- 勤務先の社会保険（106万円）の壁 ※目安

### 特定親族特別控除と扶養控除の違いを、実額で見せる

19〜22歳の人が親の扶養に入っている場合、**控除額そのものはどちらの制度でも所得税63万円・住民税45万円で同じ**です。違うのは次の2点だけです。

| | 扶養控除（特定扶養親族） | 特定親族特別控除 |
| --- | --- | --- |
| 対象（本人の合計所得） | 令和7年分 58万円以下／令和8年分 62万円以下 | そこを超えて123万円以下 |
| 給与だけなら年収 | 123万円以下／136万円以下 | 150万円・159万円で満額、188万円・197万円で0 |
| 所得税の控除額 | 63万円 | 63万円→3万円の段階 |
| 住民税の控除額 | 45万円 | 45万円→3万円の段階 |
| 段階 | なし（1円超えると0） | あり |
| 住民税の**調整控除** | 対象（人的控除差18万円） | **対象外** |

同じページの手順には、**年末調整の見込みと実際がずれたとき**の扱いも載せています。特定親族として申告して実際は扶養控除の範囲に収まった場合、控除額が同じ63万円なので<b>所得税の追徴は生じません</b>。むしろ住民税の調整控除と（親の給与収入850万円超なら）所得金額調整控除のぶん納めすぎになるので、直せば戻ります。逆に見込みより多く稼いで85万円を超えた場合は追徴です。

「特定扶養親族向け」のページに、扶養している人の給与収入をもとに**その人の税額が実際にいくら減るか**まで計算した比較表を出します。調整控除のぶん（人的控除差18万円 × 5% ＝ **最大9,000円**）だけ、控除額が同じでも実額が変わります。扶養している人の課税所得が200万円を超えていると調整控除は最低額の2,500円になるため差が出ないので、その場合はそのことも表示します。

### 健康保険の扶養に入れるかを、同居・別居で場合分けして判定する

健康保険の被扶養者は、年収の上限だけでは決まりません。**同居なら「扶養している人の年収の2分の1未満」**、**別居なら「その人からの仕送り額より少ない」**ことも要件です。「あなたの状況」で同居か別居かと仕送り額（月額）を入れると、「税額の明細」に判定カードが出ます。両方の場合を並べて表示するので、別居に切り替えたらどうなるかもその場で分かります。

| 条件 | 内容 |
| --- | --- |
| ① 年収の上限 | 原則 **130万円未満**。**19歳以上23歳未満（配偶者を除く）は150万円未満**（令和7年10月1日の認定分から）。60歳以上・障害者は180万円未満 |
| ② 同居の場合 | 扶養している人の年間収入の **2分の1未満** |
| ② 別居の場合 | 扶養している人からの **仕送り額より少ない** |

- 年齢は、認定日が属する年の**12月31日時点**で見ます（アプリの「年齢」と同じ基準です）。
- この **150万円は健康保険の話**で、税の特定親族特別控除が満額になる線とは別物です。令和8年分は税の線が給与159万円まで上がる一方、健康保険は150万円未満のままなので、**その間は親の控除が満額のまま健康保険の扶養だけ外れます**。アプリはこの食い違いを判定カードで知らせます。
- 同居で2分の1以上になった場合も、扶養している人の年収を上回らず、生計維持の中心がその人だと保険者が認めれば認定されることがあります（総合判断）。その状態のときは注記を出します。
- ここでいう収入は税の「所得」ではなく**収入そのもの**で、通勤手当・賞与・失業給付・年金・傷病手当金も含みます。業務委託から必要経費を引けるかは保険者によって違うため（協会けんぽは原則引けません）、**入力で切り替えられる**ようにしてあります。既定は協会けんぽの原則（引かない）です。
- 別居でも認定されるのは、配偶者・子・孫・兄弟姉妹・直系尊属です。それ以外の三親等内の親族は同居が要ります。
- 最終的に判断するのは加入先の保険者です。健保組合は独自の基準を持つことがあります。

### 試算枠であと稼いだ場合を試す

「給与であと◯◯円」「業務委託であと◯◯円」を**それぞれ別に**入れると、いまの入力と並べて、収入合計・合計所得・所得税・住民税・手取りがどう変わるかを比べられます。両方に入れて同時に試すこともできます。増えた収入のうち何％が手取りとして残るか、新しくどの壁を超えるかも表示します。「給与を壁の直前まで」「業務委託を壁の直前まで」のボタンは、もう一方の欄の金額を据え置いたまま、いちばん近い壁ぎりぎりの額を入れます。

### 親などにいくら負担が行くかを出す

「親などの扶養に入っている」を選ぶと、扶養している人の給与収入と社会保険料を入力できます。あなたの所得が扶養の要件を超えたときに、**その人の控除がいくら減り、税額がいくら増えるか**を所得税・住民税に分けて表示します。試算枠にも「親などの負担増」と「親の負担を引いた手取り」の行が加わるので、世帯全体で見て手取りがいくら増えるのかが分かります。

計算は本体と同じ税額計算を扶養者側の申告として実行しているので、特定親族特別控除による段階的な減り方もそのまま反映されます。

### 年齢と家族構成を計算に反映する

年齢は公的年金等控除の65歳区分、住民税の未成年非課税判定（令和4年分から18歳未満）、130万円/180万円の壁に効きます。扶養親族は1人ずつ「年齢・その人の収入・障害者区分・同居老親等」を登録でき、16歳未満／一般／特定／老人扶養／特定親族特別控除を自動で判定します。

### 扶養している人の収入と、あなたの手取りの関係を可視化する

被扶養者の給与収入を0円から振り直し、**控除が満額のときを基準にあなたの手取りが何円変わるか**を階段グラフと段階表で表示します。段階の境目は1円単位まで求めています。

## オフラインでの動作

初回に一度開けば、以後は**通信がなくても起動して使えます**。Service Worker が本体・プライバシーポリシー・アイコンを端末に保存し、画面はまずキャッシュから返します。

- 圏外でも、電波が弱くて応答が返らない場所でも、待たされずに開きます
- オフラインのときは画面上部に「オフラインで表示しています」と表示します
- 新しい版が配信されると「新しい版があります／更新する」を出します。判定は Service Worker の更新検知によるもので、同じ版を開き直しただけで出ることはありません
- 入力内容は端末内に保存されるため、オフラインのまま計算も保存も続けられます

`index.html` を書き換えたときは、`sw.js` の `CACHE` の版数も上げてください。古いキャッシュが残り続けます。

## プライバシー

入力した内容は端末内に保存されます。外部に出るのは、利用者自身が同期を有効にした場合に**利用者自身の Google ドライブ**へ送られるときだけで、開発者はその内容を見られません。解析ツールや広告の計測は組み込んでいません。詳細は[プライバシーポリシー](https://kuru77.github.io/income-tax-simulator-jp/privacy.html)をご覧ください。

## 使い方

そのまま https://kuru77.github.io/income-tax-simulator-jp/ を開けば使えます。

iPhone / Android では、ブラウザの共有メニューから「ホーム画面に追加」すると、アプリとして起動でき、オフラインでも動きます。

手元で動かす場合は、このリポジトリを clone して `index.html` をブラウザで開くだけです（Service Worker を有効にするには `http://` で配信してください）。

```bash
git clone https://github.com/KURU77/income-tax-simulator-jp.git
cd income-tax-simulator-jp
python -m http.server 8000
```

## 控除額の検証

令和7年分・令和8年分の控除額は、国税庁のタックスアンサー（いずれも令和8年4月1日現在法令等）と突き合わせて確認しています。

| 項目 | 出典 | 結果 |
| --- | --- | --- |
| 基礎控除 | [No.1199](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1199.htm) | 令和7年分（95/88/68/63/58万…）・令和8年分（104/67/62万…）とも一致 |
| 給与所得控除 | [No.1410](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1410.htm) | 令和7年分（最低65万円）・令和8年分（最低74万円）とも一致 |
| 公的年金等控除 | [No.1600](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1600.htm) | 令和2年分以後の速算表のまま（令和7・8年改正の対象外）。掲載の計算例と一致 |
| 所得金額調整控除 | [No.1411](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1411.htm) | 子ども・特別障害者等／給与と年金の双方、どちらも一致 |
| 扶養控除 | [No.1180](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1180.htm) | 38／63／48／58万円に一致 |
| 特定親族特別控除 | [No.1177](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1177.htm) | 63／61／51／41／31／21／11／6／3万円に一致 |
| 配偶者特別控除 | [No.1195](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1195.htm) | 令和7年分（58万円超〜）・令和8年分（62万円超〜）とも一致 |
| 勤労学生控除 | [No.1175](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1175.htm) | 27万円・合計所得85万円（令和8年分は89万円）以下に一致 |

この突き合わせで見つけて直した点は次の3つです。

1. **勤労学生控除**：要件の「勤労に基づく所得以外が10万円以下」を、給与所得以外すべてで判定していました。業務委託（事業所得・雑所得（業務））も自分の勤労による所得なので、いまは公的年金等・配当・不動産などだけで判定します。業務委託で稼ぐ学生が控除を受けられない誤りが直りました。
2. **所得金額調整控除**：1円未満の端数を切り捨てていましたが、正しくは切り上げです。
3. **扶養親族の所得**：給与収入しか入れられず、業務委託や年金で稼いでいる扶養親族の判定ができませんでした。配偶者と同じく「給与以外の所得」欄を足しました。

## 試算の前提と限界

概算です。実際の税額は端数処理・各種特例・お住まいの自治体の条例で変わります。申告の際は国税庁・自治体の資料でご確認ください。

- 所得税額は速算表で計算し、復興特別所得税（2.1%）を加えています。
- 住民税は所得割＋均等割で、税率と均等割額は選んだ住所から決まります（標準は所得割10%・均等割5,000円）。調整控除は人的控除の差額にもとづく簡易計算です。
- 特定親族特別控除と（令和7年分以降の）配偶者特別控除は住民税の調整控除の対象外です。そのため扶養控除・配偶者控除から切り替わる線では、控除額が同じままでも扶養している人の住民税が調整控除の分だけ（特定扶養で最大9,000円、配偶者で最大2,500円）増えます。専用ページの「追加負担が0円で済む線」はこれを織り込んで計算しています。
- 給与所得は速算式で求めており、収入660万円未満の場合に使う「簡易給与所得表」の1,000円単位の区分は考慮していません（数百円の差が出ることがあります）。
- 勤務先の社会保険（106万円）の壁は、勤務先の規模や週の所定労働時間で扱いが変わるため目安です。
- 健康保険の被扶養者の判定は、収入の上限・同居別居の条件まで見ますが、最終的に判断するのは加入先の保険者です。健保組合は独自の基準を持つことがあります。一時的に超えた場合の事業主証明など、ここで扱っていない救済もあります。
- 令和6年分以前の年分は選べないようにしています。
- 青色申告特別控除は、要件（複式簿記・e-Tax等）を満たしている前提で差し引いています。
- 同期はログインした Google アカウントごとに1つの内容を保持します。同じアカウントで複数の人の試算を使い分けることはできません。
- Android / iOS のネイティブ版（WebView）では、Google のログイン画面が埋め込みブラウザを拒むため、同期メニューを出していません。同期を使いたい場合は Web 版をホーム画面に追加してお使いください。
- 住民税の超過課税は実施期間が定められているものが多く、延長・終了があります。表示される均等割額は目安として、お住まいの自治体の最新の案内でご確認ください。
