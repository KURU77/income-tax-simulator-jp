# 所得シミュレーター

業務委託などの所得と給与所得を入れると、**その年分の税制**で年間の合計・課税額を試算し、非課税枠が残っていれば「あといくら稼げるか」を出します。

**→ https://kuru77.github.io/income-tax-simulator-jp/**

依存ライブラリなし、ビルド不要の HTML 1ファイルです。入力した金額はブラウザの中だけで計算され、どこにも送信されません。

## できること

### 年分ごとの税制を切り替えられる

令和元年〜令和8年（2019〜2026年分）に対応し、その年に実際に適用される制度で計算します。

| 年分 | 給与所得控除 | 基礎控除 | 所得税の壁 | 住民税の壁 |
|---|---|---|---|---|
| 令和元年 | 最低65万円 | 38万円 | 103万円 | 100万円 |
| 令和2〜6年 | 最低55万円 | 48万円 | 103万円 | 100万円 |
| 令和7・8年 | 最低65万円 | 58万円＋上乗せ（最大95万円） | **160万円** | **110万円** |

このほか、ひとり親控除の新設と寡婦控除の見直し（令和2年）、住民税の非課税限度額への10万円加算（令和3年度）、定額減税（令和6年）、特定親族特別控除の新設と勤労学生控除の要件緩和（令和7年）も年分ごとに反映されます。青色申告特別控除の選択肢や寡婦・ひとり親の区分も、その年に存在するものだけが表示されます。

### 収入を月ごとに入力できる

給与と業務委託の収入は、金額欄の横の「月ごと」を押すと12か月分の内訳で入力できます。年額に入れていた金額は自動で12か月に割り振られ、合計と月平均が表示されます。「1月の額を全月にコピー」で毎月同額をまとめて入れられます。

途中の月まで入力した場合は、そのペースで続けたときに**何月ごろ壁に到達するか**を試算します（年額で入れた項目は通年でならして計算します）。給与を月ごとに入れると、社会保険の106万円の壁の判定に使う「月額8.8万円」を超えた月も表示します。

### あといくら稼げるかを壁ごとに出す

これから稼ぐ分を「給与」か「業務委託」かで選ぶと、その区分で収入を増やしながら二分探索し、壁の直前の金額を求めます。

- 住民税の均等割・所得割
- 所得税
- 親などの扶養控除、特定親族特別控除（19〜22歳）
- 配偶者控除・配偶者特別控除
- 勤労学生控除
- 社会保険の106万円・130万円（60歳以上や障害者は180万円）の壁 ※目安

### 年齢と家族構成を計算に反映する

年齢は公的年金等控除の65歳区分、住民税の未成年非課税判定（令和4年分から18歳未満）、130万円/180万円の壁に効きます。扶養親族は1人ずつ「年齢・その人の収入・障害者区分・同居老親等」を登録でき、16歳未満／一般／特定／老人扶養／特定親族特別控除を自動で判定します。

### 扶養している人の収入と、あなたの手取りの関係を可視化する

被扶養者の給与収入を0円から振り直し、**控除が満額のときを基準にあなたの手取りが何円変わるか**を階段グラフと段階表で表示します。段階の境目は1円単位まで求めています。

## 使い方

そのまま https://kuru77.github.io/income-tax-simulator-jp/ を開けば使えます。

iPhone / Android では、ブラウザの共有メニューから「ホーム画面に追加」すると、アプリとして起動でき、オフラインでも動きます。

手元で動かす場合は、このリポジトリを clone して `index.html` をブラウザで開くだけです（Service Worker を有効にするには `http://` で配信してください）。

```bash
git clone https://github.com/KURU77/income-tax-simulator-jp.git
cd income-tax-simulator-jp
python -m http.server 8000
```

## 試算の前提と限界

概算です。実際の税額は端数処理・各種特例・お住まいの自治体の条例で変わります。申告の際は国税庁・自治体の資料でご確認ください。

- 所得税額は速算表で計算し、復興特別所得税（2.1%）を加えています。
- 住民税は所得割10%＋均等割で、調整控除は人的控除の差額にもとづく簡易計算です。均等割額は自治体ごとに変えられます。
- 給与所得は速算式で求めており、収入660万円未満の場合に使う「簡易給与所得表」の1,000円単位の区分は考慮していません（数百円の差が出ることがあります）。
- 社会保険の壁は、加入する健康保険や勤務先の規模によって扱いが変わるため目安です。業務委託の収入は、健康保険組合によって必要経費の扱いが異なります。
- 青色申告特別控除は、要件（複式簿記・e-Tax等）を満たしている前提で差し引いています。

## 構成

```
index.html              アプリ本体（HTML・CSS・JavaScript を1ファイルに同梱）
manifest.webmanifest    ホーム画面に追加したときの設定
sw.js                   オフライン用の Service Worker
icons/                  アプリアイコン
```

`index.html` を書き換えたときは、`sw.js` の `CACHE` の版数も上げてください。古いキャッシュが残り続けます。
